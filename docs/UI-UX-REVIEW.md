# UI/UX review: kzm.bar

Дата: 2026-11-01. Область: главная страница, типографика, ресурсы и адаптивность.

## Что изменено

| Наблюдение | Решение |
| --- | --- |
| Декоративный макет лаунчера дублирует инструкцию | Удалён; сохранены три реальных шага |
| Отдельные блоки профилей и восстановления перегружают раздел | Удалены по запросу пользователя |
| Описания 11–13px, footer 9–10px | Основной текст 1rem, второстепенный 0.875rem |
| Маленькие внутренние поля ссылок | 16px mobile, 24px wide |
| Описания искусственно ограничены 28ch | Вся доступная ширина, автоматическая высота, свободный перенос |
| Нет явной позиции против пиратства | Добавлены требование легальной копии и «Мы не поддерживаем пиратство» |
| Текст 200% с увеличенными интервалами вызывал переполнение | Поля и узкие служебные колонки не растут вместе со шрифтом; длинные слова переносятся |

## Проверки в браузере

Использован встроенный Chromium-браузер Codex с эмулируемыми размерами viewport.
Это проверка браузерной вёрстки, а не физического телефона или сенсорных жестов.

| Сценарий | Результат |
| --- | --- |
| Viewport 574×1244 | Body и описания 16px, примечания/footer 14px; поля ссылок 16px |
| Viewport 1440×1000 | Поля ссылок 24px, описания целиком, горизонтального переполнения нет |
| Viewport 320×1000 | Горизонтального переполнения и обрезанных описаний нет |
| Внутренняя ширина с полосой прокрутки | 564 / 1430 / 310 CSS px соответственно |
| Высоты отдельных ссылок/кнопок | Проверенные навигация, CTA, ресурсы, инструкция, марки и домен не меньше 44px |
| Tab между ресурсами | Фокус переходит на следующий ресурс; cyan outline 2px виден |
| Текст 200% и интервалы одновременно на узком экране | Root 32px, ширина страницы 310px при доступных 310px; переполнения проверенных блоков нет |
| Интервалы стресс-проверки | Line-height 1.5, letter-spacing 0.12em, word-spacing 0.16em, отступ после p 2em |
| Временные стили проверки | Удалены после проверки |

Во время стресс-проверки текстовая колонка ресурсов сначала сжималась до 22px;
после исправления служебных колонок и полей — 166px. Рост высоты строки сохраняет
полный текст. Для логотипа допускается адаптивный размер: он относится к марке,
а обычный текст в стресс-сценарии действительно увеличивается вдвое.

## Контраст

Расчёт относительной яркости sRGB по формуле WCAG, без округления при сравнении
с порогом 4.5:1. В таблице значения округлены только для чтения.

| Роль | Цвет текста / поверхность | Контраст |
| --- | --- | --- |
| Основной текст | `#f1eef4` / `#101014` | 16.52:1 |
| Второстепенный текст | `#b0a6b9` / `#101014` | 8.14:1 |
| Описание ресурса | `#afa0bb` / `#151118` | 7.61:1 |
| Описание ресурса при hover | `#afa0bb` / `#211727` | 7.04:1 |
| Название ресурса при hover | `#ff83b8` / `#211727` | 7.55:1 |

| Ссылка в инструкции | `#e6a4c3` / `#101014` | 9.46:1 |

## Сохранённые решения

Стиль лаунчера, оригинальные игровые ассеты, согласованная мобильная камера,
нижняя прозрачная маска, общие часы сцены 7.5 кадров/с, отсутствие ручной паузы,
reduced motion и остановка вне экрана сохранены. Новых элементов управления
или анимаций этот проход не добавляет.

## Границы проверки

Это целевая UI/UX-проверка с исправлениями, не сертификат соответствия WCAG.
Полный screen-reader-аудит, физический touch, все браузерные движки, вспышки
игровых кадров и отдельный автоматизированный axe-аудит здесь не проверялись.
Наличие и содержимое опубликованного GitHub-релиза зависят от внешнего сервиса.

Реализация также проходит `bun run check` и `bun run build`.
