# Architecture Decision Records

ADR фиксируют контекст, выбранный подход и его последствия. Дата ниже — дата
фиксации существующих и уточнённых решений, а не вымышленная история их принятия.

| ADR | Решение | Статус | Дата фиксации |
| --- | --- | --- | --- |
| [0001](0001-static-sveltekit-and-bun.md) | Статический SvelteKit, Tailwind и Bun | Принято, реализовано | 2026-11-01 |
| [0002](0002-game-scene.md) | Canvas-сцена и единые часы анимации | Принято, реализовано | 2026-11-01 |
| [0003](0003-readable-ui.md) | Типографика и адаптивные строки ресурсов | Принято, реализовано | 2026-11-01 |

Новые записи получают следующий номер. При изменении решения сохранять старый
контекст и ссылаться на заменяющий ADR. Внешний вид и токены описаны отдельно
в [DESIGN-STYLE.md](../../DESIGN-STYLE.md).
