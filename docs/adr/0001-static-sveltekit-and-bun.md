# ADR 0001: статический SvelteKit, Tailwind и Bun

Дата фиксации: 2026-11-01. Статус: принято, реализовано.

## Контекст

kzm.bar — сайт-визитка с тремя разделами и внешними ссылками. Пользователь выбрал
SvelteKit и Tailwind, затем Bun. Для страницы не нужны аккаунты, база данных
или собственная серверная логика. Сайт хранится отдельным репозиторием рядом с KZM.

## Решение

Использовать Svelte 5, SvelteKit и Tailwind CSS 4. `adapter-static` и prerender
создают сайт в `build/`. Bun устанавливает зависимости и запускает команды;
`bun.lock` и `packageManager` фиксируют рабочий процесс.

Ссылка скачивания ведёт на GitHub `releases/latest`. Документация, исходники
и поддержка автора задаются в `src/lib/links.ts`. Canonical, sitemap и Open Graph
используют будущий домен `kzm.bar`.

## Последствия

Production не требует сервера Node/Bun. Артефакт можно разместить на статическом
хостинге. Номер актуального релиза не нужно хранить в коде сайта. Доступность
самого релиза и внешних страниц зависит от их публикации в соответствующих сервисах.

Изменение runtime-поведения сервера, авторизация или получение данных на каждый
запрос потребуют пересмотра этого ADR. Подключение домена и DNS выполняются отдельно.

## Проверка

`bun install --frozen-lockfile`, `bun run check`, `bun run build`.
Каталог `build/` должен содержать HTML, локальные шрифты и спрайты без зависимости
от локальной папки экспорта игры.
