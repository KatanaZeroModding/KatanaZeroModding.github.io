# kzm.bar

Сайт KZM на SvelteKit, Svelte 5 и Tailwind CSS 4. Стиль наследует лаунчер:
Inter, Tiny5, сливовые поверхности, розовый и cyan.

## Разработка

Нужен Bun 1.4.2+. Установка зависимостей и все команды выполняются через Bun.

```sh
cd kzm.bar
bun install --frozen-lockfile
bun run dev
```

```sh
bun run check
bun run build
bun run preview
```

`bun run build` создаёт полностью статический сайт в `build/`. Папку можно
разместить на любом статическом хостинге; сервер в production не нужен.
Домен `kzm.bar` указан в canonical, Open Graph, robots.txt и sitemap.xml.
Публикация на хостинг и настройка DNS выполняются отдельно.

Проект находится в отдельном репозитории `kzm.bar`, рядом с `katana-snow` и `kzm`.

## Содержимое

- `src/routes/+page.svelte` — три блока сайта и SEO.
- `src/app.css` — тема и адаптивная вёрстка.
- `src/lib/links.ts` — ссылки на релиз, документацию, исходники и Ko-fi.
- `src/lib/BarScene.svelte` — canvas-сцена из оригинальных спрайтов.
- `static/bar/` — только спрайты для idle-сцены и статичный кадр.

Ссылка скачивания ведёт на GitHub `releases/latest`, поэтому номер релиза не
нужно обновлять в коде. Предоставленные исходники не подтверждают наличие
публичного релиза: страница должна быть опубликована сопровождающим KZM.

NULL сидит на стуле и иногда проигрывает полный цикл питья (23 кадра).
Стакан в покое совмещён со стаканом в первом/последнем кадре питья; во время
анимации отдельный стакан скрыт, поскольку уже включён в спрайт персонажа.
Посетители обращены друг к другу. Общая последовательность задаёт реплики,
паузы и ответы. Левый кивает во время реплики правого; после каждой своей
реплики правый делает паузу и затягивается (полный цикл на 24 кадра).
При выдохе появляется оригинальный `spr_cigarette_smoke` (14 кадров),
движется от лица влево и вверх и рассеивается в следующей паузе. Все действия используют
одни сценические часы. Общая скорость воспроизведения — 0.5× от исходной
(7.5 кадров/с вместо 15): движения, кивки, паузы и дым замедлены вместе.
Бармен протирает стакан в idle-цикле (11 кадров);
отдельной анимации разговора у него в оригинальном архиве нет.
Лампочки отключены. Текстовых диалогов, сюжетных переходов и звука нет.
При `prefers-reduced-motion` сцена изначально неподвижна; в скрытой вкладке
и вне экрана цикл приостанавливается. Без JavaScript остаётся статичный кадр.

## Повторный импорт сцены

Скопированные ассеты уже включены: исходная папка не нужна для обычной сборки.
Используется оригинальный NULL из Steam-версии Katana ZERO; экспорт хранится
в `../references/room_bar_vanilla`. Импорт проверяет `manifest.json` и отклоняет
экспорт с источником из Katana SNOW. При экспорте через UndertaleModCli
оригинальный `data.win` должен быть аргументом `load`: переменная
`KZM_SOUND_DATA_WIN` задаёт только источник недостающих звуков.
Для переимпорта из локального экспорта игры:

```sh
bun scripts/import-bar.mjs D:/Programming/Mods/references/room_bar_vanilla
python scripts/render-poster.py
```

Для второго скрипта нужен Pillow. Он используется только при подготовке
ассетов, а не при сборке или работе сайта.

Игровые материалы Katana ZERO принадлежат Askiisoft и соответствующим
правообладателям; лицензия исходного кода не распространяется на эти материалы.

## Проверка

`bun run check` и `bun run build` проходят. Мобильное кадрирование и desktop-
композиция проверены в браузере. Проверены общая последовательность разговора,
полные циклы питья и курения, отсутствие дублирующего стакана и совпадение его
пикселей/позиции с начальным и конечным кадром питья.
